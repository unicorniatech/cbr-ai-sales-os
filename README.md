# cbr-ai-sales-os

Initial frontend for Grupo Inmobiliario Castrejón Rodríguez.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis

## Development

```bash
npm install
npm run dev
```

The hero expects the brand video at:

```text
public/videos/CBR-introvideo.mp4
```

Supabase, authentication, and the AI advisor are intentionally not connected yet.
